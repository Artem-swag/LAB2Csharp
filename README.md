Задание 1. Базовые сущности

Задача 1. Точка координат
Создайте сущность Точка, расположенную на двумерной плоскости. Точка описывается координатами X и Y, а также может возвращать текстовое представление вида {X;Y}.

Алгоритм решения:
1.	Создать класс Coordinate_point с приватными полями _x и _y.
2.	Реализовать конструкторы: по умолчанию (0;0) и с параметрами.
3.	Создать свойства X и Y для доступа к полям.
4.	Переопределить метод ToString(), используя интерполяцию строк для вывода в формате {X;Y}.

Задача 3. Имена

Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. При приведении к строке пустые параметры не должны учитываться.

Алгоритм решения:
1.	Создать класс Fullname с приватными полями для фамилии, имени и отчества.

Задание 2. Композиция объектов

Задача 1. Прямая

Создайте сущность Линия, описываемую координатами начала и конца (с использованием сущности Точка). Если координаты точек меняются, это должно отражаться на линии.

Алгоритм решения:
1.	Создать класс Line с полями типа Coordinate_point (начало и конец).

5.	В методе Main продемонстрировать, что при изменении координаты X начала Линии 1 (через свойство line1.StartLine.X), зависимая Линия 3 также меняет свое положение, так как ссылается на тот же объект в памяти.

Задание 3. Сложные структуры данных

Задача 3. Города

Создайте сущность Город, которая имеет название и набор путей к другим городам. Путь состоит из названия города назначения и стоимости поездки. Необходимо реализовать граф по картинке.

Алгоритм решения:
1.	Создать класс Way (Путь), содержащий объект City (куда едем) и стоимость int.
2.	Создать класс City с названием и массивом путей Way[] (так как списки List не использовались, реализован ручной динамический массив с полем _waysCount).
3.	В классе City реализовать метод AddWay, который добавляет новый путь в массив, если есть свободное место.
4.	В методе ToString() класса City пройти циклом по массиву путей и собрать строку вида «Название: Сосед1:стоимость1; Сосед2:стоимость2».
5.	В Main создать 6 городов (A, B, C, D, E, F) и связать их согласно графу (учитывая двунаправленность путей).

Задание 5. Математические операции

Задача 5. Дроби

Создайте сущность Дробь (числитель и знаменатель). Дробь должна поддерживать строковое представление, а также операции сложения, вычитания, умножения и деления с другой дробью или целым числом. Результатом должна быть новая дробь.

Алгоритм решения:
1.	Создать класс Fraction с полями _nom и _den.
2.	В сеттере Den реализовать защиту от деления на ноль (если передан 0, вывести ошибку и установить знаменатель в 1).
3.	Реализовать 8 методов операций (Add, Sub, Mul, Div): 4 для работы с другой дробью и 4 для работы с целым числом (перегрузка).
4.	В методах создавать и возвращать новый объект Fraction, не изменяя исходные (реализован принцип иммутабельности).
5.	В методе Div(Fraction other) добавить проверку: если числитель второй дроби равен 0, прервать операцию и вернуть 0/1.
6.	В ToString() вывести строку в формате «числитель/знаменатель».
